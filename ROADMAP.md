# Roadmap

## Planned

- Ansible reference role with check mode and explicit secret-provider interfaces.
- High-availability patterns for split SMTP, mailbox, database, and filtering tiers.
- DANE and DNSSEC deployment profile.
- Prometheus exporter mappings and example alert rules.
- Containerized lab environment for destructive testing.
- Additional migration playbooks for common hosted and legacy platforms.

## Non-goals

- Promising inbox placement.
- Operating a public bulk-mail platform.
- Bundling credentials or production-ready private keys.
- Replacing upstream security advisories or an organization's change process.
